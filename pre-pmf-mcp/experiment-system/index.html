The Experiment System page — four directions

Option A

The Loop

Brand-familiar mountain hero. An animated five-layer loop, a noise-to-signal toggle, and a risk/reward ranking matrix.

 Option B

Signal from Noise

Dark particle hero where noise settles into a signal. A tool-stack switch, an evidence slider, a sticky scroll story, and a drop-dead-date experiment.

 Option C

Experiment Lab

Product-style page. A live experiment board, a hands-on simulator, a call-to-insight extractor, an effort vs impact planner, and a comparison table.

 Option D

Fusion

B's particle hero and tool focus, C's live board, then A's loop, ranking and tiles, with C's comparison table.
